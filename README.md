# EcoCompute – Intelligent Green IT Monitoring and Optimization System

## About the Project

EcoCompute is a Flutter-based Android application developed to promote sustainable IT practices. It helps users explore device information, understand estimated energy consumption, calculate electricity costs and carbon emissions, and identify opportunities to reduce energy wastage.

The project supports three United Nations Sustainable Development Goals (SDGs):

- **SDG 7:** Affordable and Clean Energy
- **SDG 12:** Responsible Consumption and Production
- **SDG 13:** Climate Action

## Features

- **Device Information:** Displays device details, Android version, RAM information, and battery status.
- **Energy Monitoring:** Presents estimated energy consumption and related sustainability metrics.
- **Cost Estimation:** Estimates electricity costs using a configured electricity tariff.
- **Carbon Emission Estimation:** Calculates estimated carbon emissions using a configured emission factor.
- **Optimization:** Illustrates potential energy savings using a hypothetical energy-reduction scenario.
- **Analytics:** Displays energy-related information and sustainability metrics.
- **Recommendations:** Provides suggestions for more energy-conscious technology usage.
- **Eco Score:** Displays a project-defined score to encourage sustainable practices.

## Technology Stack

- **Frontend:** Flutter
- **Programming Language:** Dart
- **Platform:** Android
- **Device Information:** `device_info_plus`
- **Battery Information:** `battery_plus`
- **Local Data Storage:** `shared_preferences`
- **Development Tools:** Android Studio, Flutter SDK

## How It Works

1. The application displays supported device information.
2. It presents energy-related estimates based on configured assumptions and available inputs.
3. It estimates electricity costs and carbon emissions.
4. It illustrates possible energy savings through an optimization scenario.
5. It displays sustainability metrics and recommendations to encourage responsible IT usage.

## Important Notes and Limitations

- Energy consumption values are software estimates, not direct measurements of actual electrical power consumption.
- Electricity costs and carbon emissions depend on configured assumptions, including the electricity tariff and emission factor.
- The optimization percentage represents an illustrative scenario, not a guaranteed or measured reduction in energy usage.
- External IT equipment is not automatically monitored by this prototype.
- The Eco Score is a project-defined metric and is not an official sustainability certification.

These limitations are stated to ensure that the results are interpreted appropriately.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or another compatible development environment
- An Android device or emulator

### Installation and Execution

1. Clone the repository:

   ```bash
   git clone https://github.com/Ruchita-Telang/EcoCompute.git
   ```

2. Navigate to the project directory:

   ```bash
   cd EcoCompute
   ```

3. Install the dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application on a connected Android device or emulator:

   ```bash
   flutter run
   ```
